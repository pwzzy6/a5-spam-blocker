# S1 a5 内容屏蔽器

一个 Tampermonkey（油猴）用户脚本：在 [stage1st](https://stage1st.com/2b/)（S1）的主题帖页面里，把正文包含 a5（哎小呜）内容的楼层折叠成占位条，点击可展开；引用块里的 a5 内容单独折叠，不影响楼层其余部分。

## 安装

**方式一：链接安装（推荐，可自动更新）**

已安装 [Tampermonkey](https://www.tampermonkey.net/) 的浏览器直接打开任一链接，Tampermonkey 会弹出安装确认页，点击「安装」即可：

- **jsDelivr（国内可直连，脚本的更新源）**：

  ```
  https://fastly.jsdelivr.net/gh/pwzzy6/a5-spam-blocker@main/s1-a5-blocker.user.js
  ```

- **GitHub raw（需海外网络或代理）**：

  ```
  https://raw.githubusercontent.com/pwzzy6/a5-spam-blocker/main/s1-a5-blocker.user.js
  ```

**方式二：手动安装**

1. 打开上面任一链接，全选复制脚本内容
2. Tampermonkey 面板 → 添加新脚本 → 粘贴 → 保存

## 更新说明（国内网络必读）

- Tampermonkey 的自动更新是浏览器后台定期请求脚本 `@updateURL`；本脚本的更新源是 jsDelivr，国内一般可直连
- 早期版本（≤ 0.1.1）的更新源是 `raw.githubusercontent.com`，该域名在国内被墙，更新检查会**静默失败**（不弹任何提示，版本号一直不变）。如果卡在旧版本：挂代理 → Tampermonkey 面板 → 实用工具（Utilities）→「检查用户脚本更新」，手动更新到 0.1.2 后即改走 jsDelivr，以后无需代理
- jsDelivr 对 `@main` 分支引用有约 12 小时缓存，新版发布后镜像端最多延迟半天；急用可直接走 GitHub raw 链接重装

## 功能

- **楼层折叠**：正文命中关键词的楼层折叠为一行「已屏蔽 a5 内容（#楼层号）· 命中「关键词」」，点击「展开/收起」切换；作者栏和楼层号保留，楼层号不断裂
- **引用块独立折叠**：别人引用了 a5 内容时，只折叠引用块本身，楼层其余内容照常显示
- **归一化匹配**：忽略全角/半角（ａ５ = a5）、大小写（A5 = a5）、空格与零宽字符混淆（`a 5`、`a​5` 均命中）；正文中的 http/https/www 链接不参与匹配，URL 里恰好含 a5 不会误封
- **豁免自己**：默认不折叠你自己发的楼层（可关闭）
- **动态生效**：翻页后新加载、动态插入的楼层自动处理（MutationObserver）
- **可配置**：Tampermonkey 图标菜单里可编辑关键词列表（每行一个）、启用/暂停、切换调试模式

## 菜单说明（Tampermonkey 图标 → 该脚本）

| 菜单项 | 作用 |
| --- | --- |
| ⚙ 屏蔽关键词与设置… | 打开设置面板：关键词（每行一个）、启用开关、豁免自己、调试模式 |
| 🐞 切换调试模式 | 命中楼层不折叠，改为红框高亮并显示命中词，用于调关键词 |
| ⏯ 启用/暂停屏蔽 | 临时暂停或恢复 |

默认关键词：`a5`、`哎小呜`。匹配为子串语义（正文归一化后包含关键词即命中），想屏蔽更多变体（如直播切片常用称呼）直接加一行即可。

## 已知局限

- **纯截图楼层无法识别**：正文一个字没有、只有图片的 repo 检测不到（不做 OCR）
- **不带协议的裸域名仍会命中**：只有 `http://`、`https://` 开头或 `www.` 开头的链接文本才豁免，`imgur.com/a5` 这类裸域名会照常命中
- **紧贴 URL、中间无任何空格/换行的正文不参与匹配**：URL 剔除按空白分词，链接与后面文字粘连在同一行且无空格时（如 `看https://x.com/a5.jpg哎小呜`）会随 URL 一并豁免
- 只在主题帖页生效（版块列表、导读、搜索页不处理）
- 只匹配正文与引用文字，不匹配图片内容、用户名和签名

## 开发

```
bun test                 # 纯函数单测（归一化 / 关键词匹配）
python3 -m http.server 8765   # 然后访问 http://localhost:8765/test/fixture.html 本地验证 DOM 交互
```

`test/fixture.html` 是复刻 S1（Discuz X3.5）楼层结构的合成数据验证页，不含任何真实帖子内容。
